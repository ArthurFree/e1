# ADR 001：本地优先

## 背景

产品定位是面向简体中文个人用户的独立 Web 笔记应用，要求离线可用、打开即用。

## 决策

所有数据（页面、正文、标签、偏好、AI 配置、附件 Blob）只保存在浏览器 IndexedDB（恢复缓冲与损坏诊断用 localStorage）；不做注册/登录、云同步、多人协作、评论、权限、支付。

## 原因

- 无服务端成本与账号体系复杂度，隐私边界清晰（数据不出浏览器）；
- IndexedDB 容量与事务能力足以支撑单用户知识库；
- 后续接入云同步时只需新增仓储适配器与冲突策略（分层架构已为此预留）。

## 结果

- AI 为可选能力：未配置时不发起任何外部请求；API Key 只存 IndexedDB。
- 被否决的替代方案：服务端账号体系（与定位冲突）、localStorage 主存储（容量与结构化查询不足）。
