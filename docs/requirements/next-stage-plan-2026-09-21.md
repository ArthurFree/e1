### 性能口径

## 5. M3：R016 知识库问答最小闭环

### 用户价值与范围

用户输入问题，应用在当前知识库内检索并展示候选片段；用户选择来源后发送给已配置模型，获得可取消、带来源入口的回答。首版面向 macOS Desktop。

- 本地 FTS 检索 + 有界一跳关系扩展，按稳定文档身份去重。
- 发送前预览标题、相对路径、实际片段、目标服务和上下文大小，可排除来源。
- 流式回答、取消、重试、来源导航；用户可显式将回答新建为文档，走统一写入通道。
- 本轮暂不加入向量数据库、云同步、跨库问答、持久对话历史、自动修改笔记或多步骤代理操作。

### 分步实施与交付

| 步骤              | 交付                                                  | 验收重点                                                                |
| ----------------- | ----------------------------------------------------- | ----------------------------------------------------------------------- |
| 0. 冻结契约与评测 | 独立 R016 需求、范围/预算/来源/状态机定义，中文问题集 | 开发前可判断什么算相关、何时拒答、何时发送                              |
| 1. 本地检索       | VaultRetriever 与可检查的检索结果                     | 限定当前库、排除回收站、稳定去重、预算截断、索引未就绪提示              |
| 2. 来源快照       | 请求级 Source Manifest 与预览                         | 预览内容与实际发送内容一致；记录 vaultId/pageId/contentVersion/片段定位 |
| 3. 问答请求       | 流式接口、取消信号、requestId/代次保护                | 切库、关闭、取消、新请求均使旧结果失效；支持非流式兼容降级              |
| 4. 引用与显式写入 | 来源卡片、引用校验、新建文档                          | 未知引用不能导航；改名后仍可定位；删除或内容变更有明确状态              |
| 5. 完整验收       | G84–G95、P35–P38、检索评测和回归证据                  | 网络失败不改文件，未点击发送不发笔记，写入仅来自用户操作                |

### 建议初始预算与语义

- FTS 候选≤20，一跳扩展后总候选≤40；最终来源≤8，总片段≤16,000 字符。这些是待评测调整的初始值，不是现有实现承诺。
- 字符上限不等同于模型 token 上限；需给问题、系统指令和输出留预算，并定义配置模型的上下文限制与超限提示。
- Manifest 固定本次请求实际使用的片段及版本。预览后来源变更时显示变化并重新选择；不能后台替换内容后直接发送。
- 默认使用已保存正文；当前文档有未保存内容时明确提示。问答不能隐式触发保存或把编辑缓冲误当磁盘事实。
- Graph 只扩展候选，不据此认定相关；保留 FTS 主命中优先级，关系索引不可用时可退化为本地 FTS。
- Source ID 校验只能证明来源在本次清单里，不能证明回答结论被来源支持。UI 使用“来源可追溯”表述，评测另查事实支持程度。
- 笔记作为不可信数据传入，不赋予工具或文件操作权限；注入测试验证程序边界，不能宣称提示词能保证模型永不受干扰。
- 首版不持久保存对话和来源片段；检索索引仍为可重建派生数据，不改变 Markdown 与历史版本格式。

### R016 验收建议

准备至少 30 个固定中文问题，覆盖精确词、同义表述、关系扩展、多文档综合、无答案和恶意笔记。为每题标注应命中的来源和不可支持的结论。

- 本地检索：建议有答案问题的 top-8 来源命中率≥90%；无答案场景可明确告知未找到足够依据。记录 10k 库检索 p95，建议目标≤1s（索引 ready）。
- 请求边界：自动化验证未发送时零模型请求、预览/发送清单一致、取消/代次隔离、未知来源不可导航、失败零写盘。
- 回答质量：使用配置模型单独做来源支持程度抽查，记录模型与样例；不把不确定的生成文本逐字一致作为 CI 门禁。
- 写入：显式新建一次生成一份文档，内容经白名单解析与统一提交，保存失败可重试且不重复创建。
